# Folio Atelier

A complete, responsive portfolio starter built with Next.js App Router, React, TypeScript, and plain CSS. The visual identity uses a pale periwinkle canvas, indigo and coral accents, expressive Fraunces display type, and an original cutout portrait at `public/hero-portrait-v2.png`.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Customize

- Update the sample name, biography, experience, project copy, and links in `app/page.tsx`.
- Adjust colors, type, and responsive styles in `app/globals.css`.
- Change page title and description in `app/layout.tsx`.

The sample email, social links, biography, and project details are placeholders; replace them with your own before publishing.
