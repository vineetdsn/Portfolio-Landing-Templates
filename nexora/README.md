# Nexora portfolio

An editorial portfolio starter built with React and Vite. The interface uses soft neumorphic surfaces, an asymmetrical hero, an original 3D sculptural image, project filtering, and responsive navigation.

## Run locally

1. Install Node.js 20 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints in the terminal.

Use `npm run build` to create a production build in `dist/`.

The project names and descriptions are sample portfolio content; replace them with your own case studies and contact details in `src/App.jsx`.
