# Portfolio Landing Templates

A collection of 10 portfolio landing page templates built with various web technologies. Each template is self-contained and can be run independently.

## Templates

| # | Template | Tech Stack | Run Command | Type |
|---|----------|------------|------------|------|
| 1 | [tidefolio](tidefolio) | React + Vite + TypeScript | `npm install && npm run dev` | SPA |
| 2 | [vineet-creative-dev](vineet-creative-dev) | Vanilla HTML/CSS/JS | Open `index.html` in browser | Static |
| 3 | [vineet-digital-craftsman](vineet-digital-craftsman) | Next.js 15 + React 19 + Resend | `npm install && npm run dev` | Next.js |
| 4 | [blue-hour-3d](blue-hour-3d) | Next.js 14 + R3F + Three.js + GSAP | `pnpm install && pnpm dev` | Next.js 3D |
| 5 | [alex-morgan](alex-morgan) | Vanilla HTML/CSS/JS | Open `index.html` in browser | Static |
| 6 | [cosmic-studio](cosmic-studio) | Vanilla HTML/CSS/JS | Open `index.html` in browser | Static |
| 7 | [nexora](nexora) | React + Vite | `npm install && npm run dev` | SPA |
| 8 | [folio-atelier](folio-atelier) | Next.js 15 + React 19 + TypeScript | `npm install && npm run dev` | Next.js |
| 9 | [vineet-digital-space](vineet-digital-space) | Vanilla JS + WebGL/Three.js | Open `index.html` in browser | Static 3D |
| 10 | [vineet-digital-craft](vineet-digital-craft) | React + Vite + R3F + Three.js | `npm install && npm run dev` | SPA 3D |

## Descriptions

- **tidefolio** — Mira Sen portfolio with underwater-inspired SVG/CSS art, 2-page SPA
- **vineet-creative-dev** — Creative frontend developer hero page with workspace image
- **vineet-digital-craftsman** — Editorial dark portfolio with Resend-backed contact API endpoint
- **blue-hour-3d** — Interactive 3D tech showroom with 5 procedural Three.js scenes
- **alex-morgan** — Frontend developer portfolio with animated owl SVG illustration
- **cosmic-studio** — Space-themed "Lost Beyond The Stars?" landing page
- **nexora** — Neumorphic editorial portfolio with asymmetrical hero and 3D sculptural art
- **folio-atelier** — Portfolio starter with periwinkle and coral theme, Fraunces display type
- **vineet-digital-space** — 3D WebGL digital workspace with 4 interactive scenes
- **vineet-digital-craft** — Portfolio cover with 3D orbit, Framer Motion, and pointer interaction

## Notes

- Each template uses placeholder/sample content. Replace names, links, and project details with your own before publishing.
- Templates with `package.json` require `npm install` or `pnpm install` before running.
- Static templates (no `package.json`) can be opened directly in a browser.
- The `vineet-digital-craftsman` template needs a `.env.local` file with Resend API keys for the contact form to work. See its `.env.example`.
