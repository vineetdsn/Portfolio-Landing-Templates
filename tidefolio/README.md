# Tidefolio — Mira Sen portfolio

A two-page React portfolio inspired by the layered, illustrated underwater reference. The artwork is built from editable SVG paths and shapes, so it stays crisp at every size and does not need a separate image asset.

## Run locally

```sh
npm install
npm run dev
```

Pages: `/` (home and selected work) and `/about` (profile and design approach). Built with React and Vite; the visual layer is custom SVG and CSS.
