# Vineet — Digital Craft

A responsive portfolio cover built with React, TypeScript, Vite, React Three Fiber, Three.js, Drei, Framer Motion, and Lucide. The hero illustration is an original generated asset. The orbit details, spark particles, pointer response, animated title, and selectable discipline chips are live interactions.

## Run locally

Requires Node.js 18+ and npm.

```sh
npm install
npm run dev
```

Use `npm run build` for a production bundle.

The web font link is an optional enhancement; local fallback stacks remain in place. The 3D layer is decorative and can be skipped by browsers without WebGL. Motion respects `prefers-reduced-motion`.
